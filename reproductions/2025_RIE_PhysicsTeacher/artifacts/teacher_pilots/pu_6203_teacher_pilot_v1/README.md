# PU 6203 Teacher Pilot Dataset v1 — 2026-09-09

This is a **construction pilot**, not a claim that the exact simulation dataset used by the 2025 paper has been recovered.

## Purpose

The dual-impulse mechanism gate is now open, so this snapshot checks whether a simulated Teacher dataset can be constructed with an auditable split protocol.

Paper-confirmed context:

- bearing: 6203;
- sampling: 64 kHz;
- classes: normal / inner / outer;
- PU source condition: 1500 rpm, 1000 N, 0.7 Nm.

Still unresolved / inferred:

- exact simulated window length used by the paper;
- exact stride;
- exact final network input transformation (raw 1-D versus a derived 2-D/time-frequency representation);
- exact simulator collision-force constants.

Therefore raw windows are retained without normalization or unconfirmed preprocessing.

## Dataset construction

- 9 independent simulation runs: 3 classes × train/val/test;
- each split uses a different simulation run and randomized initial ball phase;
- no window from one run crosses into another split;
- retained sampling = 64 kHz;
- window = 2048 samples;
- stride = 1024 samples;
- 2 windows/run;
- total shape = 18 × 2048;
- class counts = 6 / 6 / 6;
- split counts = 6 / 6 / 6.

## Short-run spectral QA warning

Each simulation run retains only about 0.06 s. Its FFT/bin resolution is too coarse for the ±2% R1/R2 characteristic-frequency acceptance rule. The file mechanism_qa.json is retained specifically to show this limitation rather than hiding it.

The physical mechanism validity of this Teacher pilot is inherited from the longer R2 signal and dual-impulse validation snapshots; the short training windows themselves are **not** re-certified by forcing a frequency peak through zero-padding or tuning.

## Current decision

**Teacher dataset construction pilot: PASS.**

**Teacher pretraining: still BLOCKED** until the paper's exact input representation / preprocessing is recovered or a formally declared reproduction fallback is chosen.
