# Generated-artifact retention policy

Reproduction claims must be auditable from repository artifacts, not only from Markdown summaries.

For each accepted physics/signal-processing milestone, keep:

- exact config snapshot and runtime overrides;
- generated twin signal data (at minimum a Git-friendly retained signal plus a full-resolution excerpt);
- spectra/feature tables used to produce reported numbers;
- signal-processing figures in SVG; local runs also keep PNG;
- per-class metrics;
- SHA-256 manifest.

Full-resolution binary `.npz` files are generated by the audit script. Fixed Git snapshots may retain a compact CSV representation plus the binary SHA-256 values to keep history manageable.
