# 6203 Twin Signal Audit Snapshot — 2026-09-09

This directory contains **code-generated** audit artifacts retained in Git so the R1/R2 signal claims can be independently checked.

## Retained data

- `data/signals_4000hz_full.csv`: complete retained 0.30 s normal / inner / outer signals after anti-aliased downsampling from 64 kHz to 4 kHz.
- `data/signals_64khz_excerpt.csv`: 10 ms full-resolution 64 kHz excerpt for direct waveform inspection.
- `tables/spectra_0_500hz.csv`: raw and envelope spectral powers used for frequency-domain verification.
- `tables/class_metrics.csv`: per-class statistics and BPFI/BPFO peak errors.
- `tables/characteristic_frequencies.csv`: theoretical shaft/BPFI/BPFO/BSF/FTF frequencies.

## Retained figures

- `figures/signal_audit_panel.svg`: time-domain + raw spectrum + envelope spectrum for all three classes.
- `figures/class_envelope_comparison.svg`: direct normal / inner / outer envelope-spectrum comparison.

## Provenance

- `config_snapshot.yaml`: base simulator configuration.
- `audit_runtime_overrides.json`: short audit-run overrides.
- `manifest.json`: SHA-256 for every committed artifact and hashes of the full-resolution NPZ files generated in the same run.

The full-resolution `.npz` files are regenerated by `scripts/06_build_audit_snapshot.py`; they are not committed in this fixed snapshot to avoid unnecessary Git-history growth.

## Limitation

Effective mass, stiffness, damping, Hertz coefficient, clearance and defect dimensions remain `INFERRED`. This snapshot supports **mechanism-level** validation, not high-fidelity waveform matching to the physical rig.
