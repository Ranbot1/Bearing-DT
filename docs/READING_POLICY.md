# 阅读与证据标准

## 目标

本仓库不是摘要收集器。每篇论文尽可能回答以下问题：

1. **DT 到底建了什么？** 轴承本体、试验台、支撑/壳体、退化状态，还是只生成虚拟信号？
2. **物理模型是什么？** DOF、Hertz 接触、时变刚度、多体动力学、FEM、缺陷扩展、摩擦/润滑等。
3. **参数从哪里来？** 设计参数、公开数据集元数据、参数辨识、模态试验、inverse PINN、手工设定。
4. **Twin 输出什么？** 位移、加速度、轴承座振动、缺陷尺寸、退化轨迹、虚拟训练样本。
5. **如何校准？** 模态频率、频谱/包络谱、统计量、CycleGAN/GAN、parameter updating。
6. **DT 数据怎么进入诊断器？** augmentation、pretraining、teacher-student KD、domain adaptation、RUL。
7. **实验协议是否真的测试泛化？** random windows、cross-condition、cross-space、unseen bearing、open-set。
8. **代码是否开源？** 官方代码 / 官方数据 / 第三方复现必须分开。

## 深读等级

- A：正文级方法信息可访问，至少核对模型、关键方程/参数、实验条件和训练机制。
- B+：官方摘要 + 方法段/accepted manuscript/机构页面，可可靠还原主链条。
- B：元数据、摘要、highlights、作者主页已核对，但方法细节不做超出证据的推断。

## 代码审计标准

“未发现官方代码”不等于“作者一定没有代码”，只表示截至审计日期未在论文页面、作者主页或 GitHub 通过标题、DOI、作者、方法缩写找到可确认的官方仓库。
